# VLAN and Inter-VLAN Routing Lab

## Description
This project demonstrates how to configure multiple VLANs and enable communication between them using a multilayer switch in Cisco Packet Tracer.

## Tools Used
- Cisco Packet Tracer

## What This Lab Covers
- VLAN creation
- Access and trunk ports
- Inter-VLAN routing
- IP addressing and subnetting

## Files in This Project
- Topology Packet Tracer file (.pkt)
- Screenshots of the network topology and configuration

## What I Learned
- How VLANs segment networks
- How a multilayer switch routes between VLANs
- How to troubleshoot basic VLAN issues
